# ربات تلگرام File ⇄ Link

یه ربات شخصی تلگرام با پایتون که **فایل رو به لینک دانلود** تبدیل می‌کنه و
**لینک دانلود رو به فایل** — هر دو جهت.

ساخته شده برای اون درد همیشگی: فایل توی تلگرامه و یه جای دیگه لازمش داری
(یا برعکس) و نمی‌خوای اول دانلودش کنی توی گوشی و دوباره دستی آپلودش کنی.

## چطور کار می‌کنه؟

| تو می‌فرستی | ربات برمی‌گردونه |
|---|---|
| 📎 هر فایلی (داکیومنت، ویدیو، آهنگ، عکس، ویس…) | 🔗 یه لینک دانلود مستقیم |
| 🔗 یه لینک دانلود مستقیم http/https | 📎 خود فایل، به صورت داکیومنت توی تلگرام |

کامندها: `/start` و `/help` برای راهنما، `/myfiles` برای ۱۰ فایل آخری که ساختی و لینک‌هاشون.

## منوی ادمین — مدیریت کاربرهای مجاز

توکن و اینا رو ول کن؛ کاربرها رو از توی خود تلگرام مدیریت می‌کنی:

۱. توی `.env` مقدار `OWNER_IDS` رو بذار آیدی عددی تلگرام خودت (از
[@userinfobot](https://t.me/userinfobot) بگیر) و ربات رو ری‌استارت کن.

۲. توی تلگرام بفرست **`/admin`** — یه منو با دکمه باز می‌شه (فقط برای
اونرها):
   - **👥 List allowed users** — لیست اونرها + همه‌ی کاربرهای مجاز
   - **➕ Add user** — ربات می‌پرسه؛ آیدی عددی طرف رو می‌فرستی و همون
     لحظه مجاز می‌شه
   - **➖ Remove user** — از لیست روی یه نفر می‌زنی و دسترسی‌ش قطع می‌شه

میانبرها هم هستن: `/adduser <id>` و `/removeuser <id>` و `/users`.
لیست توی دیتابیس SQLite ذخیره می‌شه و با ری‌استارت نمی‌پره.
`ALLOWED_USER_IDS` توی `.env` فقط برای سید اولیه‌ی لیسته.

## سرور لوکال Bot API (سقف ۲ گیگ)

اگه سرور لوکال `telegram-bot-api` رو ران کنی، سقف دانلود و آپلود
تلگرام هر دو می‌شن **۲۰۰۰ مگابایت**. دو تا راه:

- **همون سرور/کانتینر ربات (مثلاً توی دن‌بات):** باینری
  `telegram-bot-api` رو بذار توی `bin/telegram-bot-api` و
  `TELEGRAM_API_ID` و `TELEGRAM_API_HASH` رو (از
  [my.telegram.org](https://my.telegram.org)) توی `.env` ست کن —
  `start.sh` خودش سرور رو ران می‌کنه و ربات رو بهش وصل می‌کنه.
- **سرور جدا:** سرور رو هر جا ران کردی، توی `.env` ربات فقط بذار
  `BOT_API_URL=http://<آدرس سرور>:8081` و `BOT_API_LOCAL_MODE=0`.

## نصب روی DanBot Hosting (اگ AIO پنل Pterodactyl)

دن‌بات روی Pterodactyl با اگ AIO بالا میاد که تنها تنظیمش Startup
Command ـه؛ اسکریپت `start.sh` این رپو دقیقاً برای همون ساخته شده:

۱. با اگ **AIO** یه سرور بساز و این رپو رو کلون کن توش.

۲. از روی `.env.example` یه `.env` بساز و حداقل اینا رو پر کن:
   `BOT_TOKEN`،‏ `OWNER_IDS` (آیدی خودت) و `BASE_URL` — آدرس نود +
   پورتی که پنل به سرورت داده:
   `BASE_URL=http://<node>:<allocated port>` (ربات خودش روی همون پورت
   بالا میاد؛ پنل اون رو به اسم `SERVER_PORT` پاس می‌ده).

۳. توی تب **Startup** پنل، Startup Command رو بذار:

```
bash start.sh
```

۴. سرور رو استارت کن — `start.sh` venv می‌سازه، دیپندنسی‌ها رو نصب
می‌کنه، سرور لوکال Bot API رو (اگه باینری‌ش رو گذاشته باشی) ران
می‌کنه و ربات رو بالا میاره.

## محدودیت‌ها (مهم)

این‌ها محدودیت خودِ Bot API تلگرامه، نه این کد:

- ربات از تلگرام می‌تونه فایل تا **۲۰ مگابایت** دانلود کنه
- ربات به تلگرام می‌تونه فایل تا **۵۰ مگابایت** بفرسته
- دانلود از لینک، محدودیتش فقط دیسک خودته (`MAX_URL_DOWNLOAD_MB`)

اگه فایل یه لینک از ۵۰ مگ بزرگ‌تر باشه، ربات فایل رو نگه می‌داره و به جاش
لینک دانلودش رو می‌ده که الکی fail نشه. برای برداشتن سقف ۲۰/۵۰ مگ هم
می‌شه سرور لوکال خود تلگرام (`telegram-bot-api`) رو ران کرد که هر دو رو
می‌کنه ۲۰۰۰ مگ — توضیحش توی README انگلیسی هست.

## نصب با installer (راه راحت)

نصب تک‌خطی:

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/IzumiRain/TelegramFileLinkBot/main/install.sh)
```

یا دستی:

```bash
git clone https://github.com/IzumiRain/TelegramFileLinkBot.git
cd TelegramFileLinkBot
bash install.sh
```

اینستالر همه‌چیز رو ازت می‌پرسه و خودش نصب و آماده می‌کنه: **توکن
ربات**، **آیدی تلگرام اونر**، **پورت اپ** (کاملاً کاستوم — مثلاً ۲۰۲۰
یا ۶۲۰۰۱، با ستینگ `APP_PORT`)، **Base URL**، فعال‌کردن **لوکال Bot
API** و api id/hash ـش، **توکن گیت‌هاب** (چون رپو private ـه، برای نصب
و آپدیت لازمه) و پسورد **پنل وب**. جواب‌ها می‌رن توی `.env` و
دیپندنسی‌ها نصب می‌شن. از اون به بعد اجرا فقط با `bash start.sh` ـه.

## آپدیت خودکار از گیت‌هاب

- ترمینال: `bash update.sh` فقط چک می‌کنه، `bash update.sh apply`
  نصب می‌کنه
- توی تلگرام: اونر `/update` می‌زنه برای چک، `/update apply` برای نصب
- توی پنل وب: کارت Update
- خودکار: `AUTO_UPDATE=1` بذاری، هر بار با `start.sh` اول آپدیت می‌شه

توکن گیت‌هاب از `GITHUB_TOKEN` توی `.env` خونده می‌شه و هیچ‌وقت توی
آدرس ریموت گیت ذخیره نمی‌شه. بعد از آپدیت یه ری‌استارت لازمه تا کد
جدید ران بشه.

## پنل وب (GUI)

اگه `WEB_ADMIN_PASSWORD` ست شده باشه، پنل مدیریت از آدرس
`<BASE_URL>/admin` باز می‌شه: وضعیت و نسخه، چک و نصب آپدیت، مدیریت
کاربرهای مجاز (همون لیست منوی `/admin` تلگرام)، ویرایش ستینگ‌های
`.env` (پورت، Base URL، اونرها، توکن‌ها…) و لیست فایل‌های ذخیره‌شده
با امکان حذف. پسورد نذاری پنل کلاً غیرفعاله.

## هاست‌های بدون شل (مثل Botkeep)

بعضی هاست‌ها اصلاً ترمینال و شل نمی‌دن؛ فقط پنلن: رپو یا زیپ وصل
می‌کنی، یه Start Command می‌دی و کانفیگ رو توی فرم Environment
Variables وارد می‌کنی. این ربات کامل با همون مدل کار می‌کنه، چون همه‌ی
تنظیماتش رو از env می‌خونه و `.env` فقط یه راحتیه برای وقتی شل داری:

- سورس: همین رپوی گیت‌هاب (پابلیکه) یا زیپ پروژه
- Start Command: ‏`bash start.sh`
- توی Environment پنل: `BOT_TOKEN` (به‌صورت secret)، `OWNER_IDS` و
  بعد از اینکه هاست دامنه داد، `BASE_URL` رو بذار روی همون دامنه
- `APP_PORT` و `PORT` رو دستی ست **نکن** — هاست خودش پورت رو با
  `SERVER_PORT` پاس می‌ده و ربات روش گوش می‌ده
- محدودیت‌ها: لوکال Bot API اونجا نمی‌شه ران کرد (سقف‌ها همون ۲۰/۵۰
  مگ می‌مونن) و آپدیت از تب GitHub خود پنل انجام می‌شه، نه از داخل ربات

راهنمای کامل و قدم‌به‌قدمش (با جزئیات Botkeep و چک‌لیست) اینجاست:
[docs/hosting-without-shell.md](docs/hosting-without-shell.md)

## راه‌اندازی سریع (دستی)

۱. از [@BotFather](https://t.me/BotFather) با `/newbot` یه بات بساز و توکنش رو بردار.

۲. کد و پیش‌نیازها:

```bash
git clone https://github.com/IzumiRain/TelegramFileLinkBot.git
cd TelegramFileLinkBot
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
```

۳. کانفیگ:

```bash
cp .env.example .env
```

- `BOT_TOKEN` — توکن بات‌فادر
- `BASE_URL` — آدرس عمومی سرورت؛ لینک‌ها با این شروع می‌شن، مثل
  `http://IP:8080` یا `https://files.example.com`
- `OWNER_IDS` — آیدی عددی تلگرام خودت (از
  [@userinfobot](https://t.me/userinfobot) بگیر) — **حتماً ست‌ش کن**؛
  اونرها تنها کسایی‌ان که منوی `/admin` رو می‌بینن و کاربر اضافه می‌کنن
- `ALLOWED_USER_IDS` — سید اولیه‌ی کاربرهای مجاز؛ بعدش لیست از منوی
  `/admin` مدیریت می‌شه

۴. اجرا:

```bash
python bot.py
```

یا با داکر: `docker compose up -d --build`

## امنیت لینک‌ها

لینک‌ها از جنس capability URL هستن: اون توکن تصادفی توی
`/d/<token>/...` خودش پسورده. برای فایل‌های حساس لینک رو عمومی پست نکن،
و اگه می‌خوای لینک‌ها منقضی بشن `FILE_TTL_HOURS` رو ست کن.

راهنمای کامل (systemd، ریورس‌پراکسی nginx و HTTPS، سرور لوکال Bot API)
توی [README.md](README.md) انگلیسی هست.
